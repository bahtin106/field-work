# Monitor 1.1.0 (versionCode 11): Google Play release handoff

Дата подготовки: 6 августа 2026 года.

Этот файл фиксирует состав, проверки и готовый текст релиза.
Коммит релиза можно найти командой:

```bash
git log -1 -- docs/google-play-release-notes-1.1.0.md
```

## Текст «Что нового» для Google Play

Полностью обновили статистику: понятные показатели команды и личных
результатов, динамика заявок и денег, фильтры по периоду, сотрудникам,
отделам и видам работ. Добавили историю изменений заявок. Улучшили финансы,
права ролей и переводы. Исправили приём заявок из Telegram и MAX, авторизацию и стабильность.

## Что вошло в релиз

### Статистика

- Новый ролевой экран: личные показатели для каждого сотрудника и вся
  компания для администраторов и ролей с соответствующим правом.
- Периоды, произвольный диапазон дат, сотрудники, отделы и виды работ объединены
  в едином фильтре.
- Динамика заявок, выручки, прибыли и личного заработка доступна в виде
  столбцов или линий с адаптивной числовой шкалой.
- Подробности по заявкам, финансам и команде вынесены в компактные модальные
  экраны с объяснением каждого расчёта.

### Заявки, права и финансы

- Добавлена читаемая история заявки с группировкой изменений, точным временем,
  кратким описанием и раскрываемыми подробностями.
- Права доступа сгруппированы по понятным разделам; отдельно управляется доступ к
  статистике компании.
- Уточнены названия финансовых показателей, способов оплаты и личного заработка.

### Надёжность и безопасность

- Восстановлен приём заявок из Telegram и MAX при автоматическом назначении
  исполнителя; добавлен регрессионный SQL-тест обоих источников.
- Привилегированные Supabase-ключи удалены из публичной Expo-конфигурации; ключи
  перевыпущены, а в CI добавлен автоматический блокирующий сканер.
- Обновлены транзитивные зависимости; `npm audit` не находит известных уязвимостей.
